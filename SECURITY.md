# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in Penguin, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Send an email with details and reproduction steps to the project maintainer or file a private security advisory via GitHub Security Advisories tab.
3. Include the platform details (Linux distribution, desktop session X11/Wayland, Qt and libmpv versions).

We will acknowledge your report within 48 hours and work with you on a coordinated fix and security disclosure.
